01 / The engineering question

Can shape predict latency?

Given matrix dimensions M, N, K, how accurately can a model predict a dense linear operation on a fixed GPU? This project compares compute and memory proxies with shape-aware models, selects on training families, and evaluates where the predictions hold up.

The central finding

7.71–10.32% error on ordinary tests.

That range is weighted mean absolute percentage error across the four selected predictors. Warm unseen-family challenge error is about 29%; irregular-shape stress error reaches 49–57%. Timing-quality flags remain part of the result.

04 / How the study works

Collect. Select. Evaluate. Repeat.

Held-out labels are collected before fitting. Their role is evaluation; only training rows enter model selection and refitting.

01 / MEASURE

Fix the timing contract.

Preallocated tensors, CUDA events, and adaptive graph replay. Collect 3 visits of 9 replay samples per case, with FP16 and BF16 interleaved in a seeded schedule.

02 / SELECT

Hold out whole families.

Compare 19 configurations across five predictor families in 6 training-only folds grouped by N/K. Fit feature scaling inside each fold; select by weighted mean APE.

03 / EVALUATE

Refit, then assess.

Refit each family's chosen configuration on all eligible training rows: 311 for warm reuse and 266 for rotation. Evaluate ordinary test, challenge, and stress separately.

04 / REPEAT

Keep the models fixed.

Measure 77 predetermined shapes later in the same session, including 63 eligible for rotation. Compare paired timings and apply the unchanged primary models.

A precise operation-level target.

The measured interval includes GPU reads, writes, and replay/inter-kernel gaps. Allocation, host-device transfers, warmup, graph capture, profiling, fitting, and serving queues are outside it.

The operation has no bias or activation. The optional decoder-layer experiment was not run; no full Transformer or end-to-end LLM speedup was measured.

Candidates: FLOP-only, two- and three-parameter Roofline, shape-log Ridge, and Roofline residual KRR. Kernel names and profiler durations are excluded from predictor inputs.

05 / Results with boundaries

What the evidence supports.

Stage completion, measurement quality, and prediction accuracy are separate findings.

Timing quality

Complete, with qualifications.

Every requested stage completed. Six of 2,256 primary aggregate rows exceed the between-visit threshold; one of six repeat control groups also fails its threshold.

Overall timing-quality flag: false. Flagged data remain included. None of the six flagged primary rows is in the repeat subset, so the repeat does not resolve those flags.

Inspect the quality records ↗
Prediction limits

Coverage still matters.

Warm unseen-family challenge error is about 29% weighted mean APE. Irregular stress reaches 49.47–57.31%; its N/K alignment states have no matching training examples.

Some comparator models perform better on these held-out slices. The training-selected KRR remains fixed. These are point estimates from one primary collection.

Same-session repeat

Typical agreement. Real exceptions.

Across the four contexts, median absolute timing changes are 1.18–1.61%. The largest paired change is 28.19%, even though that shape passes each stage's internal checks.

The 77-shape subset uses the same recorded physical GPU and software session. It does not establish cross-day or cross-architecture transfer.

Scope and limitations

One hardware/software configuration. NVIDIA A100-SXM4-40GB, PyTorch 2.11.0+cu130, CUDA runtime 13.0, and driver 580.82.07. The primary collection and repeat share the same physical GPU.

Buffer rotation has a specific contract. Four buffer sets do not guarantee cold-cache execution or complete cache eviction. Hardware counters, measured cache-hit rates, and Tensor Core utilization were not collected. Recorded latency differences do not prove a hardware mechanism.

Evaluation has now been inspected. These cases document the current model's strengths and failures. Future model changes need new final evaluation cases for fresh generalization claims. No calibrated per-shape prediction interval is provided.

Archived measurements. This explorer filters published results. No GPU timing, fitting, or model selection runs in the browser.
