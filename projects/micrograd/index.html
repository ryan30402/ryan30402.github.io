Under the hood

Reverse-mode autodiff.

The central idea is to build a graph of scalar operations and propagate gradients backward in reverse topological order.

micrograd.ipynb · Value.backward()PYTHON
def backward(self):
    topo = []
    visited = set()

    def build_topo(v):
        if v not in visited:
            visited.add(v)
            for child in v._prev:
                build_topo(child)
            topo.append(v)

    build_topo(self)
    self.grad = 1.0
    for node in reversed(topo):
        node._backward()
What this implements

A tiny differentiation engine

Each Value records its scalar data, gradient, predecessor nodes, operation, and a local backward rule. Calling backward() walks the graph and accumulates gradients.

The notebook then assembles Neuron, Layer, and MLP classes and checks a neuron gradient calculation against PyTorch.

Takeaways

What the exercise demonstrates.

01

Chain rule in code

Small local derivative rules can be composed across a full computation graph.

02

Gradient accumulation

Multiple paths through a graph require gradients to add together rather than overwrite one another.

03

Networks are compositions

Neurons, layers, and MLPs can be built from the same scalar primitives.
